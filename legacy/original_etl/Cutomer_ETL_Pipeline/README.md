# Customer Feedback ETL Pipeline

## 📌 Overview
This project implements an end-to-end ETL pipeline:
- **Extract**: Load customer feedback from CSV.
- **Transform**: Clean text & analyze sentiment with TextBlob.
- **Load**: Store structured data in PostgreSQL via SQLAlchemy.
- **Visualize**: Dashboard in Streamlit.

## ⚡ Tech Stack
Python, Pandas, TextBlob, SQLAlchemy, PostgreSQL, Streamlit
