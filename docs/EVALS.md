# AI Evaluation Methodology
SafeVision treats evaluation as product-quality discipline. The suite contains 100 cases across 20 failure modes. Traditional classification metrics include accuracy, macro precision, macro recall, and macro F1. Product-quality dimensions use a 0–2 rubric for sentiment correctness, extraction, grounding, recommendation quality, and hallucination control. The same eval set should be rerun for every model/prompt version to detect regressions. Hosted LLM evaluation is optional; the free-first project can run VADER/TextBlob locally and later add local transformer models.
